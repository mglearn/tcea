Entry / Exit Ticket Item Analysis Tool

Analyze CSV assessment data, group students by phase of learning, identify SOLO levels, and generate ACE Framework recommendations aligned to selected TEKS.

1. Paste CSV Data

Required format: one row per student. Include a student column and question score columns such as Q1, Q2, Q3. Use 1 for correct and 0 for incorrect. The tool runs fully in the browser with vanilla JavaScript only.

2. TEKS Alignment Settings

TEKS text should be verified against current district/TEA documentation before official use. This tool supports alignment planning; it does not replace curriculum review.

3. Item Purpose Map

Edit these labels to match your entry or exit ticket. The tool uses them to create more specific recommendations.
