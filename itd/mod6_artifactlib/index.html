How the Documents Work Together

Incident Intake (3) → Incident Response Plan (1) + 24/48-Hour Checklist (2) → Texas Decision Matrix (4) → Executive Brief (7) + Communications Packet (8) + Notifications (5-6) → Quick Runbooks (9) → Risk Register (11). Vendor review (10) and data handling/encryption (12) reduce the likelihood and impact of future incidents.

District Scenario Used Across the Set

Several artifacts use incident AISD-IR-2026-004, a third-party student-support portal compromise affecting 3,240 potentially viewed student records, to demonstrate how a technology director moves from facts to state reporting, parent notice, executive briefing, vendor remediation, and public communication. A separate employee-data example demonstrates Texas Business & Commerce Code Chapter 521 notification workflow when Social Security numbers are involved.
