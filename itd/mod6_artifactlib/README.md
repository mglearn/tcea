# Ardent ISD - Module 6 Cybersecurity and Data Privacy Artifact Library

Static, GitHub-ready artifact library for the TCEA IT/Tech Director Certification Module 6.

## Contents

- `index.html` - library landing page
- `complete-library.pdf` - combined 52-page printable library
- `docs/` - web-viewable HTML versions
- `markdown/` - editable Markdown source versions
- `pdf/` - printable PDF versions
- `assets/style.css` - TCEA-aligned navy/gold styling
- `sources.html` - authority and source notes

## Publishing with GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. In repository **Settings → Pages**, choose deployment from the main branch/root.
3. The library uses only relative links and requires no build step.

## Important

These documents are training samples. Localize them to current district board policy, administrative procedures, records-retention rules, cyber-insurance terms, and legal counsel guidance before operational use.
