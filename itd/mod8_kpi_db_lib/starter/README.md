# KPI Dashboard Starter

1. Edit `data.md` with sanitized or approved data.
2. Keep the `## KPI Cards` table headers intact, or revise the HTML parser if you intentionally change the structure.
3. Test with `python -m http.server 8000` and open the served URL in a browser.
4. Publish the folder to an approved static web host such as GitHub Pages.
5. Verify every value and public-release decision before sharing.

The HTML includes embedded fallback sample data for demonstration when opened directly from disk. On a web server, it loads `data.md`.
