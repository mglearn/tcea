Use this catalog as a starting point, not as a requirement to track everything. A good executive dashboard normally contains a small number of measures that answer current leadership questions.

GenAI data guardrail: Use fictional, public, aggregated, or properly sanitized information with public generative AI tools. Do not enter student records, staff records, personally identifiable information, credentials, sensitive cybersecurity details, legal records, confidential procurement material, vendor-confidential information, or sensitive district project information unless your district has explicitly approved the tool and data use.

How to Use the Catalog

  1. Start with the decision or leadership question.
  2. Select the smallest set of KPIs that answers it.
  3. Define the formula and data source locally.
  4. Establish a baseline before setting an ambitious target.
  5. Name an owner for the measure and an owner for the response.
  6. Decide what action is triggered when the KPI is off target.
  7. Review whether the KPI is still useful after the project or service stabilizes.
