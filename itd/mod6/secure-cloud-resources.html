Three

Encrypt files before cloud storage

Client-side encryption protects a file before it reaches cloud storage. The cloud provider stores the encrypted version rather than receiving the readable original.

Cryptomator

Open-source client-side encryption designed for files stored in cloud services. It creates encrypted vaults that work with common cloud-sync folders.

Official site Documentation

CipherSplat

Browser-based file encryption with client-side processing so files can be protected before they are uploaded or shared.

Open CipherSplat

Paranoia Works

Browser and mobile encryption tools for text, files, and other content.

Official site

7-Zip

Desktop archive utility that supports AES-256 encryption in 7z and ZIP workflows.

Official site

Keep the key separate

If an encrypted file and its password travel through the same compromised channel, encryption provides much less protection. Share passwords or keys through a separate approved channel.

Four

Safeguard email and attachments

An encrypted message does not automatically mean every attachment is protected in every workflow. Match the protection method to the sensitivity of the information and the recipient’s ability to receive it securely.

Proton Mail

Encrypted email service with zero-access encryption and options for protected messages to external recipients.

Official site

Tuta Mail

Secure email, calendar, and contacts with end-to-end encryption features across desktop and mobile platforms.

Secure email

Hushmail

Encrypted email service with secure-message pickup for recipients outside Hushmail.

Official site How encrypted email works
Secure sharing

A simple attachment workflow

Use this when district policy allows file-based encrypted sharing and the recipient can follow the same process.

Agree on a tool

Confirm the recipient can open the encrypted format you plan to use.

Share the password separately

Use an approved secure channel, such as Signal, rather than the same email thread.

Encrypt the file

Create the protected archive or encrypted file before attaching it.

Send minimal context

Keep unnecessary sensitive details out of the email body and subject line.

Verify receipt

Confirm the recipient received and successfully opened the protected file.

Useful companion tools

Signal can provide a separate encrypted messaging channel. CipherSplat, Paranoia Works, and 7-Zip provide file-protection options.

Before using any security tool

Follow district policy for sensitive information, approved storage, encryption, accounts, software installation, retention, and sharing. A technically secure tool may still be inappropriate if it conflicts with organizational requirements.
