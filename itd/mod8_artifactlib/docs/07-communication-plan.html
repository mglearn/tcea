Project Communication Plan: Staff MFA Rollout

Communication goal: Ensure each stakeholder understands why MFA is being implemented, what action is required, when it is due, where to get support, and how the district will handle access barriers.

Message Standards

Every user-facing message should answer five questions:

  1. Why is this changing?
  2. What do I need to do?
  3. When do I need to do it?
  4. What if I cannot use the standard method?
  5. Where do I get help?

Sample Staff Update

Action needed: Enroll in MFA by January 8
Ardent ISD is adding multi-factor authentication to staff accounts to strengthen account security. Enrollment takes about five minutes. Complete the setup before January 8 so you can test it before enforcement begins January 11. If you cannot use the standard method, contact the Help Desk for an approved alternative. Instructions and support times are available on the staff technology portal.

Communication During a Problem

If the project causes a widespread access issue:

  • Confirm facts before issuing a districtwide message.
  • State what is affected, what is not affected, what users should do, and when the next update will be provided.
  • Avoid technical speculation.
  • Maintain one approved source of truth for status updates.
  • Use the incident / outage communication process if normal project support is no longer sufficient.
