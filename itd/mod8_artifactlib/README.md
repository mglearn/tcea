# Module 8 Artifact Library

A GitHub-ready static site for the TCEA Technology/IT Director Certification, Module 8: Project Management and Change Leadership.

## Contents

- `index.html` - library landing page
- `docs/` - browser-viewable HTML artifacts
- `markdown/` - editable Markdown source files
- `pdf/` - print-ready PDF versions

## Publishing on GitHub Pages

1. Upload the contents of this folder to a GitHub repository.
2. In repository Settings > Pages, publish from the branch/root folder containing `index.html`.
3. The site uses only local HTML/CSS and does not require a build process.

## Artifact set

The collection includes 12 core artifacts plus two bonus CTO-focused samples covering adoption/support and de-implementation.
