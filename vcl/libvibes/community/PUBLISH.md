# Publishing an approved community LibVibe

1. Save the approved submission's single HTML file as:
   `vcl/libvibes/community/<slug>/index.html`
2. Add one entry to `vcl/libvibes-community.js`:
   `{ slug: "<slug>", title: "<Title>", by: "<Name>", level: "beginner|intermediate|advanced", blurb: "<one line>" },`
3. Commit & push. It appears automatically on `libvibes-community.html`.
