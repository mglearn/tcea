District Assessment System Vendor Cards

Flip through public-info snapshots for common K-12 assessment platforms. Use this as an early screening aid before demos, security review, and reference checks.

How to read the score

The score is an estimated fit against a district assessment-system rubric using public product information. It is not a final RFP score. Require vendor-provided evidence before procurement.

Use in an RFP: Treat these cards as a pre-screen. Ask each vendor for security documentation, accessibility conformance, data-export details, implementation scope, item-bank licensing, interoperability support, and references from districts similar to yours.
