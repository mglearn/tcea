# Idiom Spotlight — image list (optional illustrations)

The idiom spotlight on the landing (`index.html`) is **text-only by design** and works without images.
These are **optional** illustrations that would make it more engaging for multilingual learners: each image
shows the idiom's **literal, playful meaning** (the funny picture the words paint) — which contrasts with the
figurative meaning shown in text. That contrast is the whole teaching point.

## How to use
- Put finished images in **`breakouts/idioms/img/`** using the **exact filename** in the table below.
- The spotlight auto-displays `img/<slug>.webp` when it exists and **hides gracefully** if it doesn't, so you
  can add them a few at a time.
- **Format:** `.webp` (preferred; PNG is fine — convert to .webp). **Square 1:1**, ~600×600 px, small file size.
- **Style (keep consistent):** flat, friendly **cartoon/vector** illustration; **teal `#0e7490` + amber
  `#f59e0b`** accents on a light or transparent background; **no text in the image**; one clear subject.
- **Keep it K–12 appropriate** — the notes flag the few idioms (kill two birds, bite the bullet, speak of the
  devil) that should be drawn **playfully and non-violently / without literal devil imagery**.
- **Alt text** is provided for accessibility; the page sets it automatically.
