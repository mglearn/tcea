How to use these

Each breakout works as a bellringer, station, partner activity, or short investigation. Project it for a whole-class analysis, or let pairs work through the sources. Every lock ends with a short why so the reasoning sticks, not just the answer.

  • Each grade card opens a teacher launch page (no answer key shown) with a button to start the student breakout.
  • Answers for all twelve breakouts are in one password-protected teacher answer key covering every grade band — keep the password private.
  • Self-contained: each page is a single HTML file. The only outside request is Google Fonts. No data is collected.
