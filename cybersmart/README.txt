CyberSmart READY — Educator Cybersecurity Tabletop Exercise

Open index.html in any modern browser. The site is fully self-contained: a single
HTML file with no external libraries, no build step, and no network connection
required (web fonts load from Google Fonts when online, with system-font fallbacks).

Includes 30 scenarios — six per module, one per CyberSmart Educator capacity-matrix
indicator — plus a scenario generator, a filterable/searchable library, a NIST CSF 2.0
reference, a coverage map, and a team-advancement die.

The scenario data lives inline in index.html (the single source of truth), so the
game runs offline straight from the file. Styling and interaction follow the TCEA
"When Disaster Strikes" (wds) look and feel.
