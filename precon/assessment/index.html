Turn Assessment Data Into Action

Facilitators: Diana Benner & Miguel Guhlin

About Agenda Tools Reading

About This Session

Formative assessment can double student learning gains, but only if the data actually changes what you do next.

In this hands-on, three-hour workshop, you'll build engaging low-stakes assessments using both no-tech and digital tools, compare AI tools for generating quality assessment items, and turn ticket data into action by grouping students by phase of learning (surface, deep, transfer).

Results map to the SOLO Taxonomy and match to concrete next steps with the ACE Framework (Articulate, Connect, Extend). You'll leave with ready-to-use templates, a prompt library, a repeatable workflow, and the confidence to move from raw data to targeted instruction by Monday morning.

Best for: K–12 teachers, instructional coaches, and campus leaders.

Agenda

Three hours, four blocks, bookended by entry and exit tickets that model the workflow being taught.

0:00–0:05 · Entry Ticket

Set the baseline

A one-question Mentimeter poll: "How confident are you turning assessment data into next-day instruction?" Live results frame the day.

0:05–0:38

Foundations: What & When Guhlin

  • Welcome, goals, norms
  • Why formative assessment doubles learning gains; the learning gap
  • Phases of learning mapped to the SOLO Taxonomy; shared vocabulary
Transition: Turn-and-talk in pairs — "Name one thing you currently assess that's really just surface-level." A few share out.
0:38–1:15

Building the Assessment Benner

  • Checks for understanding: TAPPLE, the four feedback questions
  • Human Bingo as a live formative check; play, then redesign squares by learning phase
  • Debrief: what the activity reveals about students
Transition: Quick thumbs vote — "Could you run Human Bingo Monday? Up / sideways / down." Signals readiness and cues the break.
— Break · 1:15–1:25 —
1:25–2:08

Digital & AI Tools Benner

  • Digital tools tour: Mentimeter, Plickers, Socrative, Poll Everywhere, Google Forms
  • AI item generation: Conker, QuestionWell, MagicSchool, Quizizz AI, chatbots
  • Guardrails: quality-checking AI output, avoiding invented content
Transition: "Tool speed-date" — each participant posts a one-line "why I'd use this" to a shared board before moving on.
2:08–2:55

From Data to Action: Smart Item Analysis Guhlin

  • Model the water-cycle entry ticket; item types mapped to phases
  • Live item analysis demo: reading percentages, grouping by phase, generating ACE next steps
  • Hands-on, two paths: Gen AI–assisted vs. the free browser tool (no data leaves the device); run sample CSV
2:55–3:00 · Exit Ticket

Commit & capture

A two-question Google Forms exit ticket: "What's the first thing you'll try, and what's one question you still have?" Responses model the workflow and give facilitators follow-up data.
