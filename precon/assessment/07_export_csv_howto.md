# How to Export Your Data as a CSV

A CSV (comma-separated values) file is the format the AI reads best. Here is how
to get one out of the most common gradebooks and tools.

## Google Forms (quiz responses)
1. Open your Form -> Responses tab.
2. Click the green Sheets icon to open results in Google Sheets.
3. In Sheets: File -> Download -> Comma-separated values (.csv).

## Google Sheets (any grade data)
- File -> Download -> Comma-separated values (.csv).
- If you have multiple tabs, only the active tab is exported.

## Microsoft Excel
- File -> Save As -> choose "CSV (Comma delimited) (*.csv)".

## Canvas gradebook
- Grades -> Export (or Actions -> Export Entire Gradebook) -> downloads a CSV.

## Schoology
- Gradebook -> gear/Options -> Export -> CSV.

## Before you upload
1. Replace student names with numbers or initials (S01, S02, ...).
2. Make sure each question column is scored 1 (correct) or 0 (not yet), OR
   include a scoring key (see 06_scoring_key_template.md) so the AI can convert.
3. Label each question column with the phase it measures, e.g. Q3_deep.
