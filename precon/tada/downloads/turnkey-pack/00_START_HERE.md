# Turn Assessment Data Into Action
## Turnkey Item Analysis Pack - for any Gen AI chatbot

This pack lets you go from a spreadsheet of student responses to a phase-tagged,
ACE-recommended item analysis in about 10 minutes, using ANY Gen AI chatbot
(ChatGPT, Claude, Gemini, Copilot, Z.ai, Mistral - free versions work).

You do NOT need a special tool. You need three things:
  1. Your student data as a CSV file  (use 02_item_analysis_template.csv)
  2. A context primer the AI reads first  (01_context_primer.md)
  3. A conversation starter you paste in  (03_master_prompt.md)

--------------------------------------------------------------------
## The 5-minute quickstart

STEP 1.  Open your chatbot. Start a new chat.

STEP 2.  Attach or paste 01_context_primer.md.
         (If your tool can't attach files, paste its contents into the chat.)

STEP 3.  Paste the master prompt from 03_master_prompt.md.

STEP 4.  Attach or paste your CSV. Not sure how to make one? Use
         02_item_analysis_template.csv as a model, or open
         04_sample_class_data.csv to practice first.

STEP 5.  The AI returns: item analysis (% correct per question), a phase of
         learning per student (Surface / Deep / Transfer), a SOLO level, and
         an ACE next step (Articulate / Connect / Extend) for each group.

STEP 6.  Run the audit. Paste 05_audit_checklist.md and ask the AI to check
         its own work against it. This catches invented data and bad matches.

--------------------------------------------------------------------
## PRIVACY - read this before you upload anything

Never put student names or PII into a public AI tool. Use student numbers or
initials. The template is already set up this way. If you cannot de-identify,
use the no-AI browser tool instead:
https://mglearn.github.io/tcea/sia/itema.html

## What's in this pack

  00_START_HERE.md ................ this file
  01_context_primer.md ............ paste FIRST; teaches the AI the frameworks
  02_item_analysis_template.csv ... blank template; fill with your data
  03_master_prompt.md ............. the conversation starter to paste
  04_sample_class_data.csv ........ 10-student practice set (water cycle)
  05_audit_checklist.md ........... verify the AI's output; catch errors
  06_scoring_key_template.md ...... map raw answers to Surface/Deep/Transfer
  07_export_csv_howto.md .......... export a CSV from Google, Excel, or your LMS
  08_ace_next_steps.md ............ what Articulate / Connect / Extend look like

Built to accompany "Turn Entry Tickets Into Smart Item Analysis" (TCEA TechNotes).
Frameworks (SOLO, ACE, ALDO, effect sizes) draw on John Hattie's Visible Learning.
